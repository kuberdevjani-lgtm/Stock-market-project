# Stock-market-project
# Stock Market Prediction Using PyTorch

## About the Project
This project explores the use of deep learning to predict stock prices based on historical market data. I built it using Python and PyTorch, focusing on Apple's (AAPL) stock.

## How It Works
- Collected historical stock data using Yahoo Finance.
- Used closing prices and standardised the data.
- Created 30-day sequences to predict the next day's closing price.
- Built a two-layer LSTM model using PyTorch.
- Trained the model and tested its predictions against actual stock prices.

## Results
- Training RMSE: 4.37
- Testing RMSE: 6.33

The project also includes a comparison of predicted and actual stock prices.

## What I Learned
Through this project, I gained practical experience with Python, PyTorch and LSTM models. It also helped me understand how machine learning can be applied to financial time-series data.

## Tools & Libraries
Python, PyTorch, Pandas, NumPy, Matplotlib, Yahoo Finance and Scikit-learn.
